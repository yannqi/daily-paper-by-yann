- **方向：**多模态｜VLA；预训练与数据｜持续预训练、异构机器人数据

- **论文：**https://huggingface.co/papers/2611.08373

## 2. Decoupled Predictive Decision Making: A Shared Conditional Predictor for Agents

**摘要：**将语言模型的语义编码与共享预训练条件预测器解耦，利用部署历史为工具判断、候选偏好和推理评估提供预测，无需更新两者参数。

- **方向：**LLM架构与推理｜决策解耦；预训练与数据｜结构化数据预训练
- **热度：**114赞 · 1条讨论 · 热度117

- **论文：**https://huggingface.co/papers/2611.02075

## 3. VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding

**摘要：**用轻量草稿器一次预测点、框或轨迹的完整坐标，按视觉原语结构调整输出布局，直接接受结构合法的预测，不要求与自回归目标逐词一致。

- **方向：**多模态｜视觉语言模型、视觉规划；推理｜结构化并行解码
- **热度：**96赞 · 1条讨论 · 热度99
- **为什么值得看：**明确区分空间预测精度与逐词一致性，值得对照无损投机解码，研究何时可利用输出结构直接并行预测。
- **论文：**https://huggingface.co/papers/2611.08449

## 4. Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training

- **方向：**LLM训练｜Agent强化学习、训练轨迹构造
- **热度：**56赞 · 4条讨论 · 热度68

- **论文：**https://huggingface.co/papers/2611.04277
